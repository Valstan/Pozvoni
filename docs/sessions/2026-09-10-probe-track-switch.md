## Сессия 2026-09-10: проба видит выключатель записи, `shell: bash` везде (PR #86)

**Седьмая проверка пробы прода — выключатель записи поездок.** Проба читает
`TRACK_RECORDING` из окружения службы и сверяет с живым ответом приложения на анонимный
`POST /api/track {action:"start"}`: включено — обязано быть 401 (гейт просит войти),
выключено — 404. Расхождение — красный прогон: «в окружении стоит одно, а служба отвечает
другое» — ровно та поломка, после которой владелец видит «кнопка есть, а поездка не
начинается» (правка окружения без перезапуска службы). Запрос безопасен по построению:
для `start` гейт в роуте стоит ПЕРВЫМ, до проверки `installId` и до любой записи в базу —
проба не может завести поездку.

**`defaults: run: { shell: bash }` во всех четырёх workflow** (письмо brain 2026-09-05,
[G322]): без явного shell раннер ubuntu зовёт `bash -e {0}` без `pipefail`, и первый же
будущий конвейер в шаге зеленел бы молча. Пайпов в шагах сегодня нет — строка
профилактическая, по одной на файл.

**Письмо brain** по трём проверкам 2026-09-05 уходит этим же PR: cookie сессии — мы в

день большой выкатки — два несвязанных риска в одном окне); stderr ssh — сделано ранее;
`draft: true` — не применимо; `shell: bash` — поставлено здесь.
