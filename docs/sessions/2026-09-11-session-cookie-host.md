## Сессионная кука `__Host-` — сессия 2026-09-11

Обещано brain письмом 2026-09-10 (класс #285: сосед по зоне `вмалмыже.рф` мог поставить
доменную куку `payload-token`, и наш сервер прочёл бы её как свою — а по сессии у нас есть
необратимое действие, привязка единого входа). Сделано в одном PR:

- `cookiePrefix: "__Host-payload"` в `payload.config.ts` — константа из
  `lib/session-cookie.ts`, там же атрибуты и `clearSessionCookies()` (гасит новое и старое
  имя, `Path=/`, без `Domain`). Роуты выхода и удаления аккаунта берут имя оттуда, а не из
  конфига внутри `try`: раньше при отказе `getPayload` роут выхода погасил бы не ту куку.
- ⚠️ **Находка аудита, без которой план из handoff сломал бы вход в админку:** парольный
  вход ставит куку сам Payload, и `Secure` он берёт только из `auth.cookies` коллекции
  (умолчание `false`). `__Host-` без `Secure` браузер отбрасывает молча — вход ходил бы по
  кругу «вошёл — снова форма», ни смоук, ни проба этого не увидели бы. Поэтому в
  `collections/Users.ts` — `cookies: { secure: true, sameSite: "Lax" }`, `domain` не
  задавать никогда.
- `Secure` всегда, включая `next dev` (`publicOrigin().secure` теперь константа `true`):
  `localhost` — доверенный origin. Разработка по LAN-адресу с телефона этим ломается —
  тогда https-туннель.
- Цена, принятая осознанно: куки админки `-theme` и `-lng` Payload пишет без `Secure` из
  своего кода, с префиксом браузер их отбрасывает — тема и язык админки не запоминаются.
  Выход из админки штатной кнопкой оставит мёртвую куку до истечения (2 часа) — это не
  «выход не сработал», сессия на сервере отозвана.
- Проба прода (`remote-probe.sh` §5) теперь смотрит на `Set-Cookie` роута выхода:
  `__Host-payload-token`, `Secure`, `Path=/`, без `Domain`. Парольный вход она не покрывает.
- Проверено локально в браузере: `POST /api/users/login` → `/api/users/me` отдаёт
  пользователя (кука принята), `/admin` открывает дашборд, выход через `/api/auth/logout`
  гасит обе куки и `/me` даёт `null`; `document.cookie="__Host-payload-theme=…"` браузер
  отверг — регресс темы подтверждён.
- Не закрыто из класса: `csrf` в `payload.config.ts` не задан — см. «Следующие шаги» п.0.
