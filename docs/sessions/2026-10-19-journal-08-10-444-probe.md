## Проба 444 — не стоит

- `return 444` на боксе нет нигде; `default_server` на :80 держит конфиг соседа;
  чужой Host → 200 с контентом соседа; наши имена → 200; `nginx -t` зелёный.
- PR #103 добавлял `default_server` в пример — на бокс он не выкатывался и как
  был не применим: дубль `default_server` валит `nginx -t` (а за ним рестарт).
- Пример `deploy/nginx.conf.example` исправлен: честная шапка, `listen 80` без
  `default_server`, закомментированный catch-all с `return 444` — на будущую
  согласованную замену (варианты А/Б в письме; ждём от brain).

## Журнал 08.10 — пять уроков

1. **Индекс journald сломан — поиск работает.** Окна `--since/--until` для 08–09.10
   отдают пусто при живых записях; `-n` не доходит до свежих строк; `--list-boots`
   перемешан. Живой способ — `--grep` по содержимому всего журнала (это не разовый
   трюк: режим «поиск» в инструменте, PR #178).
2. **Падение ≠ краш.** 02.09 крэш-луп печатал `Migrating` каждые 5 с (авторестарт),
   08.10 — одна строка и тишина: процесс завис, а не упал. Подпись дедлока — «старт
   без повтора».
3. **Дедлок из стартовой миграции.** v1 звал Local API Payload из `up()` — вызовы
   ждут `init`, `init` ждёт миграций; в журнале ни исключения, ни стека. v2 — SQL,
   11 мс. Урок: никакого Local API в стартовых миграциях.
4. **Границы свидетелей OOM.** В syslog не пишется ни одной ядерной строки
   (kern.log отсутствует), журнал ядерных строк не отдаёт (`journalctl -k` пуст),
   dmesg живёт с 10.10. «OOM не найден» честен только там, где видно, — так и
   сказано в письме. Виток OOM теперь печатает список файлов и счётчик строк ядра.
5. **Шум stderr journalctl — не ошибка.** Подсказка о группах (три строки) и
   «Pass -q…» печатаются рядом с кодом 1 при пустой выборке; код 1 при `--grep` —
   это «записей нет». Классификатор в скрипте различает пустой результат, шум и
   настоящие ошибки (неразобранный шаблон).
